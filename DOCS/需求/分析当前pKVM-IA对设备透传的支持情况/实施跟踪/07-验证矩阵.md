# pVM 设备透传验证矩阵

## 当前目的

把后续实施结果按阶段验证，而不是等所有代码写完再一次性试运行。

## 阶段性验证

### V0: 拆分与设计确认

- 目标:
  - 任务拆分清晰。
  - 每个 P0 子任务有明确验收标准。
- 当前状态:
  - 已完成。

### V1: 启动阻塞解除

- 覆盖任务:
  - T1
- 验证点:
  - pVM attach VFIO 设备后，不再因旧 shadow spgt 残留 refcount 命中 donate `-EBUSY`。
  - `host_initiate_donation()` 不再打印相同类型的 busy_hpa 错误。
- 当前状态:
  - 已完成首轮验证（2026-03-23，`NoIommu` 路径）。
- 当前证据:
  - 未再出现 `host_initiate_donation: page refcounted`、`do_donate failed ret=-16`、`pkvm: exception`。
  - 旧 `pgtable_unmap_leaf` assertion 已消失。
  - 当前失败点已迁移到更后面的 vCPU `EFAULT`，说明 V1 阶段阻塞已解除。

### V2: runtime DMA mirror 可用

- 覆盖任务:
  - T2
  - T3
- 验证点:
  - guest donate 新页后，`pgstate_pgt` 中可见对应 mirror 映射。
  - IOTLB flush 后设备能 DMA 到该页。
  - mirror 路径不引入新的 `hyp_page.refcount` 占用。
- 当前状态:
  - 已完成首轮编译与运行验证（2026-03-27，`NoIommu` + protected pVM + NVMe VFIO）。
- 当前证据:
  - 已在可复用 `.config` 的构建树上完成 host 内核增量编译验证。
  - guest 已启动到 login prompt，且枚举到 `nvme0n1`。
  - guest `dmesg` 已出现 `nvme nvme0: pci function 0000:01:00.0` 与队列初始化日志。
  - guest 已完成对 `/dev/nvme0n1` 的直接读取，以及 `mkfs.ext4 -F /dev/nvme0n1`。
  - host `dmesg` 全程未见 `DMA Read NO_PASID` / `PTE Read access is not set`。
  - guest 关机退出后，host `dmesg` 仍未见新的 teardown 相关报错。
- 当前剩余缺口:
  - 同一内核下的重复启动回归尚未补齐。
  - `BOOT-009` 已由 `B4` 修复并固定到内核提交 `b86cfd0230b9`，当前不再作为 V2 的开放阻塞。
  - 文件系统级写入校验若要作为硬证据，需要补一轮显式 mount 后的 NVMe 写入/回读。

### V3: teardown 生命周期正确

- 覆盖任务:
  - T4
- 验证点:
  - VM destroy 前设备 DMA 已被 quiesce。
  - guest 页 undonate 回 host 后，不存在设备继续访问这些页的路径。
  - 不依赖 VFIO device object 先释放。
- 当前状态:
  - 已建立验证样例，待执行。
- 当前证据:
  - 源码层面已确认 T4 对应的是 teardown 生命周期风险，而不是已经独立复现的 panic 签名。
  - 首轮 guest 关机退出观察里，host `dmesg` 未见新的 DMAR / IOMMU fault。
- 当前剩余缺口:
  - 当前负例观察不足以证明“设备 DMA 已真正 quiesce”。
  - 还没有覆盖活跃 I/O + host 强制 destroy、重复 boot/destroy、活跃 I/O + guest 强制 reboot 这三类触发样例。
  - 具体触发与判定规则见 `04A-P0-teardown-DMA生命周期风险验证与触发样例.md`。

### V4: 热插拔 / remove-path / 回滚

- 覆盖任务:
  - T5
  - T6
- 验证点:
  - attach 时 guest 已经有已 donate 页，DMA 视图可用。
  - FILE_DEL / device release 后，pKVM 内部状态同步收敛。
  - attach 失败不会留下半初始化状态。

## 回归检查

- host 非 pVM shadow IOMMU 路径不回归。
- 非 protected VM 路径不回归。
- 非透传 pVM 启动路径不回归。
- noncoherent IOMMU 场景下 `pgstate_pgt` coherency 切换不回归。
