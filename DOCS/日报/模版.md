# 工作日报模板

> 本模版用于每日工作记录的书写规范。
> 核心原则：说人话、不造词、记录迭代过程、所有引用带路径。

---

## 文件命名

```
YYYY-MM-DD-简要标题.md
```

示例：`2026-04-15-B5-2问题解决记录.md`

---

## 内容结构

### 1. 标题

```markdown
# XXXX 年 X 月 X 日 工作记录
```

如果当日有明确主题，可以加副标题：

```markdown
# XXXX 年 X 月 X 日 — 主题
```

### 2. 今日目标（可选）

一句话说清楚今天要干什么。

### 3. 过程记录

这是日报最核心的部分。格式是**迭代式推进**：每解决一个问题A，就会暴露问题B，记录要如实反映这个过程。

#### 3.1 发现问题 / 初步现象

- 描述看到的异常现象
- 附关键日志（原始节选，不是口头概括）
- 说明最小影响范围

#### 3.2 根因分析

- 给出定位过程（怎么找到的）
- 追调用链（用 text 代码块放缩进调用链）
- 说明根因是什么（用大白话解释为什么出错）

#### 3.3 解决方案

- 说了什么、做了什么
- 对应内核 commit（如果有）
- 改了哪些文件（带路径）
- 验收结果是什么

#### 3.4 下一阶段

- 修复后验证结果
- 验证通过则写明
- 验证失败则记录新出现的签名

**注意**：每解决一个问题后，如果验证过程中出现了新签名，必须作为下一个阶段继续写，不要另起一篇文档。日报按时间顺序一气写完。

### 4. 今日未完成

列出今天没有处理完的事项，分条写，每条写清楚阻塞原因。

### 5. 明日计划

列出明天的待处理项，标注优先级。

---

## 关联引用规范

所有引用的文档、commit、issue 都必须带完整路径或编号，禁止只写文件名或编号。

### 本地文档

```markdown
对应文档：`DOCS/需求/xxx/xxx.md`
```

### 内核 commit

```markdown
对应内核 commit：`abc123def456`（简短描述）
```

### GitHub issue / PR

```markdown
关联：`pkvm-x86#123`
```

### 原始日志文件

```markdown
原始日志：`DOCS/需求/xxx/raw/xxx.log`
```

### 验证记录

```markdown
验证记录：`DOCS/需求/xxx/实施跟踪/验证记录/xxx.md`
```

---

## 格式注意事项

- 调用链统一用 text 代码块，里面用缩进表示层级
- 关键日志节选用 text 代码块，不做删减关键信息
- 每个解决阶段标题写清楚"第几阶段、解决了什么问题"
- 用词和行文保持大白话，不刻意使用技术术语缩写
- 不要在日报里写方案设计，日报只记录"做了什么、结果是什么"

## 示例结构

```markdown
# XXXX 年 X 月 X 日 — 主题

## 今日目标

解决 protected pVM 透传 NVMe BAR 访问时 Guest EPT 建图报错的问题。

## 过程记录

### 阶段一：发现 crosvm metadata 没提交

#### 现象

metadata ioctl 命中数为 0，`pkvm_mmio_allow_hit()` 永远返回 0。

#### 根因

boot 阶段 PCI 设备走的是 `generate_pci_root()`，没有调用 metadata 提交流程。

#### 解决

- 补齐 `generate_pci_root()` 的 metadata 提交
- 对齐 `crosvm/hypervisor/src/kvm/x86_64.rs` 的 ABI 布局

#### 结果

metadata ioctl 命中。

### 阶段二：metadata 通了但出现 BOOT-012

#### 现象

host dmesg 出现新签名：

```text
pkvm: host_initiate_donation: addr not in mem_range addr=0xfe800000
```

#### 根因

调用链：

```text
guest 访问 BAR GPA
    pkvm_vm_mmu_map()
        __pkvm_host_donate_guest(hpa)
            host_initiate_donation()
                find_mem_range(hpa)
                    // BAR 地址不在 RAM mem_range
                    // 失败
```

`__pkvm_host_donate_guest()` 是给 RAM 页设计的，PCI BAR 地址不应走这条路。

#### 解决

- 对应内核 commit：`abc123def456`
- 改动：`pKVM-IA/arch/x86/kvm/pkvm/mmu.c`

#### 结果

BOOT-012 签名消失。

### 阶段三：BOOT-012 修好后出现 BOOT-013

（继续记录）

## 今日未完成

- xxx：阻塞原因是 yyy

## 明日计划

1. [P0] xxx
2. [P1] yyy

## 关联引用

- 内核 commit：`abc123def456`
- 关联：`pkvm-x86#20`
- 原始日志：`DOCS/xxx/raw/xxx.log`
- 验证记录：`DOCS/xxx/验证记录/xxx.md`
```
